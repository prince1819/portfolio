# Prince Patel — Portfolio

Responsive personal portfolio featuring cloud and web development projects, a professional portrait, scroll animations, and a cursor trail.

Built with HTML, CSS and JavaScript. No build step required.

## Local preview

Run `python3 -m http.server 8000` from this folder and open http://localhost:8000.

## GitHub Pages

In Settings → Pages, choose Deploy from a branch, then main and / (root).
