# Student Task Tracker — Version 8

A responsive task-management web application built with HTML, CSS and JavaScript as an AI-assisted development exercise.

Features:
- Add, edit, and delete tasks, with task name, category, priority, assignee, status, and optional due date
- Dashboard counters for total, pending, in-progress, and completed tasks
- Search and filter by status and priority
- Rule-based task suggestions (not a live AI model)
- Browser-local storage for tasks (no cloud syncing, no shared accounts)

Live demo (GitHub Pages): https://prince1819.github.io/portfolio/version8/

The project was developed with AI coding assistance. Generated suggestions and code were reviewed, tested and refined. No private API keys or server connection are required.

Note: Each visitor sees their own task data stored in their current browser.
